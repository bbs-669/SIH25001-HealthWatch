# Frontend - Smart Community Health Monitoring Dashboard (Phase 2)

This directory is reserved for Phase 2 of the Smart India Hackathon (SIH25001) prototype.

### Planned Components:
- **Interactive Epidemiological Map**: Leaflet / Mapbox GIS map of rural Northeast India (Assam, Meghalaya) color-coded with village risk levels (Green, Yellow, Orange, Red).
- **Early Warning Alert Feed**: Real-time alerts on water contamination spikes and symptom clusters.
- **ASHA Offline-First PWA**: Progressive Web App with local caching (IndexedDB) for offline field reporting and auto-sync.
- **PHC Resource Dispatch Portal**: District health administration dashboard to monitor inventory and approve ORS / chlorine tablet dispatches.
